## Fix 1 — CRITICAL: Thermal LUT CV scaling formula (vco.rs + worker.rs)

**Problem**: `base_lut[i] * temp_ratio` only compensates for V_T change, not Is(T) or other semiconductor temperature effects. The error compounds across the 21-step temperature range.

**Approach**: Solve at 2 endpoints (step 0 and step 21), linearly interpolate intermediate steps. This captures the full circuit model at both extremes and is only 2x the cost of the current single-solve.

**Files**: `plugin303/src/dsp/vco.rs` (recalculate_luts_sync_with_recal ~line 700), `plugin303/src/dsp/worker.rs` (~line 47)

**Pattern** (same in both locations):
```rust
// Replace temp_ratio scaling block with:
self.set_thermal_internal(0);
let lut_lo = self.solve_cv_lut_with_recal(recal_scale);
local_luts[0] = lut_lo;

self.set_thermal_internal(21);
let lut_hi = self.solve_cv_lut_with_recal(recal_scale);
local_luts[21] = lut_hi;

for step in 1..21 {
    let t = step as f64 / 21.0;
    for i in 0..LUT_K {
        local_luts[step][i] = lut_lo[i] + t * (lut_hi[i] - lut_lo[i]);
    }
}
```

Worker thread: restore the `sequence_checker` abort between the two solves (check after lut_lo, before lut_hi).

## Fix 3 — HIGH: Boundary extrapolation uses unvalidated anchors (vco.rs)

**Lines**: 620-629 in `solve_cv_lut_with_recal`

**Fix**: Add `is_finite()` checks on `lut[1]`, `lut[2]` (for low boundary) and `lut[last-1]`, `lut[last-2]` (for high boundary) before computing step. If intermediate anchors are non-finite, fall back to nominal LUT values for those boundary positions.

```rust
if !lut[0].is_finite() || (self.measure_freq(lut[0]) / midi_hz(lut_midi(0)) - 1.0).abs() > 0.05 {
    if lut[1].is_finite() && lut[2].is_finite() {
        let step = lut[2] - lut[1];
        lut[0] = lut[1] - step;
    } else {
        lut[0] = nominal_lut[0]; // safe fallback
    }
}
// Same pattern for lut[last]
```

## Fix 4 — HIGH: Interior anchor convergence validation (vco.rs)

**Lines**: 606-618 in `solve_cv_lut_with_recal`

**Fix**: After the main loop, add a validation pass. For any interior anchor where `best_err > 0.05` (5% relative error) or `!lut[i].is_finite()`, interpolate from nearest valid neighbors:

```rust
// Post-loop validation pass for interior anchors
for i in 1..LUT_K-1 {
    if !lut[i].is_finite() || (self.measure_freq(lut[i]) / midi_hz(lut_midi(i)) - 1.0).abs() > 0.05 {
        // Find nearest valid neighbors and interpolate
        let prev = (0..i).rev().find(|&j| lut[j].is_finite()).unwrap_or(0);
        let next = (i+1..LUT_K).find(|&j| lut[j].is_finite()).unwrap_or(LUT_K-1);
        let t = (i - prev) as f64 / (next - prev) as f64;
        lut[i] = lut[prev] + t * (lut[next] - lut[prev]);
    }
}
```

Place this BEFORE the boundary fallback code.

## Fix 6 — MEDIUM: Voice::reset drift seed desync (voice.rs)

**Line**: 882

## Fix 10 — MEDIUM: measure_freq warm-up floor (vco.rs)

**Line**: 474

Current working tree has `0.150`. Committed diff has `0.020`. This is an accuracy/performance tradeoff. Leave the committed value (`0.020`). If the working tree has a different value, it should be committed or reverted.

Note: The 20ms floor means 960 samples minimum warm-up at 48kHz (vs 144 at the old 3ms). With the 2-endpoint thermal solve (Fix 1), total LUT build = 2 × 37 anchors × ~12 secant iterations × ~2000 ticks ≈ 1.8M ticks. At 48kHz that's ~37s of simulated time, which takes ~100ms wall-clock. Acceptable for background thread.
