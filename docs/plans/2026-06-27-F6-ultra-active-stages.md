# Ultra Active-Stage Headroom (F6) Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Close the Ultra tier's residual ~4.4 dB spectral LSD by modeling the vcf303's active stages — the inverting Q9 resonance feedback (the real "cutoff"/resonance mechanism) and the AC-coupled T20/T21 readout — plus a per-note VCO pitch secant; then post-merge DAW smoke-test.

**Architecture:** Expand the `LadderVcf` nodal system from the passive 10-node ladder to include two input nodes (`in_l` signal / `in_r` feedback), an inverting AC-coupled Q9 CE-amp feedback path injecting into `in_r`, and an AC-coupled T20 readout. The Q9 loop is solved **in-loop** (zero-delay, inside the Newton iteration) so it regenerates near fc exactly as ngspice does — replacing the current 1-sample-delayed `k_reso·out_prev` hack. The VCO gets a per-note refined-CV LUT built once at construction via secant against the solver's own realized pitch (RT-safe lookup at `set_freq`). High tier inherits every VCF gain (shared `LadderVcf`).

**Tech Stack:** Rust (`plugin303` crate), nodal MNA + Newton (existing `ladder_wdf.rs` / `vco.rs` / `linalg.rs`), ngspice via PySpice (`eval/303/run_vcf303_spice.py`, `eval/303/voice_ref_spice.py`) as ground truth, Welch spectral gate (`tests/common/mod.rs`).

## Background — what is known (read before starting)

- **`eval/303/VCF_MAP.md` §8–§11** is the authoritative dig. Summary:
  - The passive diode ladder's dominant pole is structurally **~47 Hz** (cascaded-RC, ~60× below the single-section `r·C` estimate). Raising the bias only lifts the Rust corner to a **~600 Hz ceiling** before the diodes freeze (`LadderVcf::CAL` note, `corner_vs_cutoff` diagnostic). You cannot reach 1–2 kHz cutoff from the passive ladder.
  - **§11: resonance + the audible cutoff come from the active inverting Q9 CE-amp**, AC-coupled (`C23` 1µF) from the output → inverting gain ≈ `Rc9/R71` ≈ 27k/2.2k ≈ 12× → AC-coupled → `Rreso` (resonance pot) → **`in_r`, the OTHER diff input**. Because Q9 inverts and feeds `in_r`, the loop is **negative at DC** (stable, flat) but **positive near fc** once the ladder's phase lag rotates the sign → an **fc-tracking peak up to ~20 dB**. Injecting `in_l` instead just flattens (wideband negative feedback) — confirmed wrong.
  - ngspice `run_vcf303_spice.py --reso` peak-frequency map (the F6 target): **532 Hz @16µA → 1.0 kHz @32µA → 1.7 kHz @64µA → 2.7 kHz @128µA**, `Rreso` sweeps Q to ~47k optimum, stock loop self-limits (no self-oscillation).
- **Current Rust `LadderVcf`** (`plugin303/src/dsp/ladder_wdf.rs`): 10 passive nodes (`tl..dl`/`tr..dr`), differential Norton drive into `dl,dr` from a single `vin = (x + k_reso·out_prev)·vscale`, reads `tl−tr` directly. The `k_reso·out_prev` term is a **1-sample-delayed single-ended hack** — NOT the inverting-into-`in_r` topology. `set_cal`/`CAL=1.0` is the current spectral optimum.
- **Current Rust `Vco303`** (`plugin303/src/dsp/vco.rs`): `set_freq(hz)` → `cv_for_freq` quadratic `CV_FIT` fit to THIS solver (~1.4% residual per note). `set_cv` exists for diagnostics.
- **Gates today:** Ultra `tests/ultra_spectral.rs` LSD 4.42 dB / corr 0.977 (budget ≤5.5 / ≥0.95). High `tests/high_spectral.rs` LSD 28.78 / 0.971 (≤32 / ≥0.95). Shared Welch helpers in `tests/common/mod.rs`. Gold `eval/303/gold/voice_A2_mid.f32` (+ `.json` sidecar: note 57, cutoff 1002 Hz, reso 0.85, sr 48 k), regenerated by `eval/303/gen_gold.py`.

use plugin303::dsp::ladder_wdf::LadderVcf;

## Risks / stop-and-ask

- **Algebraic Q9 loop convergence.** Folding the feedback into the Newton solve creates an algebraic loop; if iters blow up or the homotopy can't find the devices-ON branch (cf. the ACME NO-GO, VCF_MAP §12 — ngspice's robustness was the whole reason this is bespoke), STOP. Fallback: a **one-sample-delayed but inverting-into-`in_r` AC-coupled** feedback at the 4× rate (5.2 µs delay ≈ 4° at 2 kHz) — less faithful but stable. Decide with the user before switching approaches.
- **Ultra cost.** N grows ~10→14 (LU is O(N³)); Ultra is already 117 % of one core. If it becomes impractical, the active stages may need to ship **High-only** (High at 2× has headroom) with Ultra kept as the reference. Surface the number, don't silently degrade.
- **If Ultra LSD does not drop** after F6.3+F6.4, the active model isn't matching the gold — debug against `vcf303_reso_gold.json` / `run_vcf303_spice.py --reso` before touching any budget (never loosen a gate to pass).
