## Control Mapping Specifications

### 1. Left Panel (Classic Front Panel Controls)
- **Knobs (Row of 7 Silver Cylindrical Knobs):**
  - **Tuning:** Fine pitch adjustment (`tuning`).
  - **Cutoff:** Main VCF cutoff control (`cutoff`).
  - **Resonance:** Main VCF resonance control (`resonance`).
  - **Env Mod:** Filter envelope modulation intensity (`env_mod`).
  - **Decay:** Classic decay time (`decay`).
  - **Accent:** Accent sweep/level boost intensity (`accent`).
  - **Volume:** Master output level (`volume`).
- **Waveform Selector:** Vintage silver slide switch: `SAW` / `SQUARE` / `SWEEP` (`waveform`).
- **Fidelity Tier Slider:** Brushed red slider switch selecting the emulation depth: `LOW` / `HIGH` / `ULTRA` (`tier`).

### 2. Right Panel (Souped-Up Engine Drawer)
- **Detune & Mix Section:**
  - **OSC1 Detune & OSC2 Detune:** Individual pitch shifts (`osc1_pitch`, `osc2_pitch`).
  - **OSC2 Mix:** Relative blend slider between oscillators (`osc2_vol`).
- **VCF Tap Toggle:** Toggles the slope tap: `2-POLE` / `3-POLE` / `4-POLE` (`vcf_taps`).
- **VCF Drive & Slew:**
  - **OSC1 PW / Sweep:** Modulates PolyBLEP pulse-width or VCO circuit morphing (`osc1_pw` / `sweep_pos`).
  - **Sub-Osc Vol:** Sub-oscillator square wave volume (`sub_vol`).
  - **VCF Drive:** internal filter saturation level (`vcf_drive`).
  - **Glide Time:** Slew rate for slide/glide steps (`glide`).
- **VCA Env Mode:** Toggles VCA response: `GATE` / `ENV` (`vca_env_mode`).
- **Analog Character Dials:**
  - **Component Age:** Controls wear calibrations (`comp_age`).
  - **Thermal Drift:** Adjusts LFO pitch/cutoff random walk walk scale (`comp_drift`).
- **Envelopes (MEG & VEG):**
  - **Advanced Env Toggle:** Enables advanced ADSR layout (`advanced_env`).
  - **MEG sliders:** Attack, Decay, Sustain, Release (`meg_attack`, `meg_decay_adj`, `meg_sustain`, `meg_release`).
  - **VEG sliders:** Attack, Decay, Sustain, Release (`veg_attack`, `veg_decay_adj`, `veg_sustain`, `veg_release`).

### 3. Bottom Panel (16-Step Sequencer Grid)
- **Transport Controls:**
  - **Note Gate:** Button toggling active gate step recording (`seq_run`).
  - **Slide / Accent:** Dedicated step modifiers (`slide`, `accent`).
  - **Tempo / Sync / Length:** Knobs and indicators for step configurations (`seq_tempo`, `seq_sync`, `seq_length`).
- **Sequencer Step Buttons (1–16):**
  - Horizontal grid of 16 square translucent buttons, illuminated in blue or amber.
  - Displays step gate status (Note / Tie / Rest).
  - Displays octave offset (`+1` / `0` / `-1`).
